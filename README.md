# 🎬 Luminous Movies

A modern full-stack movie streaming web application built with React.js, Bootstrap, TMDB API, and Supabase.

## ✨ Features

* Trending Movies
* Top Rated Movies
* TV Shows
* Seasons & Episodes
* Genre Pages
* Authentication System
* Watchlist
* Responsive Netflix-style UI
* Toast Notifications
* Dynamic Routing
* Supabase Backend

## ⚡ Tech Stack

* React.js
* Bootstrap
* Supabase
* TMDB API
* React Router
* React Toastify
